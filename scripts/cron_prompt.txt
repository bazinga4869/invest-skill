## 任务：自动化每日股票分析（cron 触发）

你被 cron 定时拉起，需要独立完成一次完整的 7+1 专家团深度分析。

### Step 0：选股

1. 用 Python 读取 data/stock_pool.json（全 A 股池），过滤：
   - 排除 688 开头（科创板）
   - 排除 8 开头（北交所）
   - 排除名称含 ST 的股票
   ```python
   import json
   pool = json.load(open('data/stock_pool.json'))
   valid = [s for s in pool if not s['ts_code'].startswith('688') and not s['ts_code'].startswith('8') and 'ST' not in s.get('name','')]
   ```

2. 读取 data/auto_state.json，获取 `next_index` 和 `last_analyzed` 映射

3. 从 valid[next_index] 开始，找到第一只满足条件的股票：
   - 该股票的 ts_code 不在 `last_analyzed` 中，或距今 > 5 天
   - 如果当前 next_index 指向的股票 5 天内已分析过，next_index += 1 继续找
   - 找到后记录 code = 该股票的 ts_code

4. 如果 next_index 超出 valid 长度，从 0 循环

### Step 4：写评估
用 Edit 工具，将报告中"## 六、LLM 专家评估区"的占位内容替换为完整的 6.1~6.8 评估。

格式要求：
- 每位专家一节，表格呈现检查结果
- 逐项判定 PASS/WARN/VETO，引用报告中的具体数据
- 无法从报告中判断的项标记"🔵 待查"
- 0-100 评分，裁决 PASS/WARN/VETO
- 裁判长 6.8 节做加权综合（权重见 config.yaml）+ VETO检查 + 最终结论

### Step 5：更新状态
更新 data/auto_state.json：
- `last_analyzed[code]` = 当天日期（ISO 格式）
- `next_index` = 当前 index + 1（如果循环了则正确取模）
- `history` 数组追加本次记录

### Step 6：更新修订历史
报告底部的修订历史改为当天日期 + "cron 自动分析"，管道标注 invest_tool（Tushare）。

### 关键约束
- 不要修改报告的数据部分（一~五章 + 复核报告）
- 评分只能基于已有数据
- 不要跳过任何专家
- 认知风控官触发 WARN≥3 → 综合分打 8.5 折
- Graham Number / 股价 < 0.5 → 强制 HOLD/SELL
- **注意：你是在 cron 环境下被拉起的，不是嵌套在另一个 Claude 会话中。正常执行即可。**
