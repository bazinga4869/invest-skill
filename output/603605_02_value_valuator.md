# 02-价值估值师评估 — 珀莱雅（603605.SH）

## 总体判断

珀莱雅是一台赚钱机器——连续12年盈利、ROE常年25%以上、毛利率73%、账上现金50亿、几乎零有息负债。但价格不在安全边际区间：Graham Number 36.33元只有现价61.80元的58.8%，DCF悲观情景（36.87元）远低于现价，基准情景（65.49元）仅勉强覆盖现价。简单说，**公司质地优秀，但价格已经把优秀定价进去了**。2025年营收和利润首次双降更是给估值假设敲了一记警钟。给予48分，verdict WARN——不触发VETO，但格雷厄姆框架下的安全边际严重不足。

## 详细分析

### 1. Graham Number 计算

首先需要从最新年度（2025）财务数据中提取EPS和BVPS：

- **EPS（每股收益）** = 归母净利润 / 总股本 = 14.98亿 / 3.96亿股 = 3.78元 [calc: 14.98/3.96; inputs: annual.annual_data[11].net_profit_yi, market.total_shares_yi]
- **BVPS（每股净资产）** = 归母权益 / 总股本 = 61.41亿 / 3.96亿股 = 15.51元 [calc: 61.41/3.96; inputs: balance.equity_yi, market.total_shares_yi]

Graham Number = √(22.5 × EPS × BVPS) = √(22.5 × 3.78 × 15.51) = √(1319.9) = **36.33元** [calc: sqrt(22.5*(14.98/3.96)*(61.41/3.96)); inputs: annual.annual_data[11].net_profit_yi, market.total_shares_yi, balance.equity_yi]

Graham Ratio = 36.33 / 61.80 = **0.588** [calc: sqrt(22.5*(14.98/3.96)*(61.41/3.96))/61.80; inputs: annual.annual_data[11].net_profit_yi, market.total_shares_yi, balance.equity_yi, market.close]

| Graham Ratio 区间 | 判定 | 当前是否命中 |
|---|---|---|
| ≥ 1.5 | 极度低估（BUY信号） | ❌ |
| 1.0 ~ 1.5 | 低估 | ❌ |
| 0.67 ~ 1.0 | 合理偏贵 | ❌ |
| **< 0.67** | **高估（HOLD/观望）** | **✅ 命中** |
| < 0.5 | 极度高估 → VETO | ❌ 未触发 |

结论：Graham Number 落入「高估」区间，但不触发VETO（比率 > 0.5）。格雷厄姆框架明确要求此时「需要更强的护城河和成长来支撑估值」——这笔债需要后续的护城河分析师和成长质量师来还。

### 2. 盈利收益率 vs 无风险利率

盈利收益率 = 1 / PE_TTM = 1 / 16.6002 = **6.02%** [calc: 1/16.6002; inputs: market.pe_ttm]

无风险利率：所提供的宏观数据中不含10年期国债收益率。Shibor隔夜1.41% [source: macro.indicators.shibor.overnight_pct]，Shibor 1周1.453% [source: macro.indicators.shibor.week_pct]——这些是短期利率，低估了长期无风险回报水平。以2026年中常见的中国10年期国债收益率约2.5%–2.8%估计（标注：数据不可得，此为分析师假设），取2.5%：

| 条件 | 阈值 | 实际值 | 判定 |
|---|---|---|---|
| 盈利收益率 ≥ 2×无风险利率 | ≥ 5.0% | 6.02% | ✅ **PASS** |
| 盈利收益率 1× ~ 2× 无风险利率 | 2.5% ~ 5.0% | — | — |
| 盈利收益率 < 无风险利率 | < 2.5% | — | — |

即使无风险利率取到3.0%（2× = 6.0%），盈利收益率仍勉强过关。不触发VETO。

### 3. PE 历史分位

❓ **数据不可得**。所提供数据仅含当前 PE TTM = 16.60 [source: market.pe_ttm]，缺少历史逐日/逐月PE序列。无法计算近5年分位。根据方法论，无法做此检查时需要标注并降级置信度。从已知的经营数据倒推：若2025年归母净利润14.98亿与总市值244.71亿 [source: market.total_mv_yi] 计算，隐含PE ≈ 16.3倍，与PE_TTM基本吻合。就化妆品行业而言，16倍PE不算极端——但这是主观判断，不是来自数据的结论。

### 4. 清算价值底线（NCAV）

NCAV = 流动资产 − 总负债。资产负债表细节不足，无法精确计算流动资产。但可以做底线测试：

- 总负债 = 总资产 − 归母权益 = 84.87 − 61.41 = 23.46亿 [calc: 84.87-61.41; inputs: balance.total_assets_yi, balance.equity_yi]
- 仅现金一项 = 50.61亿 [source: balance.cash_yi]，已远超总负债
- 应收账款 0.70亿 [source: balance.accounts_receiv_yi]，存货 6.35亿 [source: balance.inventories_yi]
- 保守估计流动资产 ≥ 57.66亿（仅现金+应收+存货）
- NCAV粗估 ≥ 57.66 − 23.46 = 34.20亿，每股 ≥ 8.64元
- 股价 61.80远高于任何NCAV估算值 → **无资产底线保护**

对比标准刻度：股价 < NCAV × 2/3（烟蒂级安全）远不成立；股价 > NCAV × 2（无保护）确定成立。这不是资产故事——这是盈利和成长故事。

### 7. DCF 多情景估值

使用TTM自由现金流 FCF_TTM = 14.60亿 [source: quarterly.fcf_ttm_yi]，总股本 3.96亿股 [source: market.total_shares_yi]，每股FCF = 3.69元 [calc: 14.60/3.96; inputs: quarterly.fcf_ttm_yi, market.total_shares_yi]。

采用5年显式预测 + 永续终值模型：

| 参数 | 悲观 | 基准 | 乐观 |
|---|---|---|---|
| 5年FCF增速 | 0% [assumption: 悲观情景假设零增长，反映营收已见顶风险] | 3% [assumption: 基准情景假设低速永续增长，接近GDP增速] | 5% [assumption: 乐观情景假设新品牌接力恢复增长] |
| 永续增长率 | 0% [assumption: 悲观永续零增长] | 2% [assumption: 基准永续为通胀水平] | 3% [assumption: 乐观永续略高于通胀] |
| WACC | 10% [assumption: 悲观情景折现率，提高风险溢价] | 8% [assumption: 基准情景折现率，化妆品行业中等风险] | 8% [assumption: 乐观折现率与基准相同，折现率不因假设乐观而降] |

**DCF 计算过程（基准情景）**：

FCF逐年增长3%，折现到现值：

Y1: 14.60×1.03 = 15.04，PV = 15.04/1.08 = 13.93
Y2: 15.04×1.03 = 15.49，PV = 15.49/1.08² = 13.28
Y3: 15.49×1.03 = 15.95，PV = 15.95/1.08³ = 12.67
Y4: 15.95×1.03 = 16.43，PV = 16.43/1.08⁴ = 12.08
Y5: 16.43×1.03 = 16.93，PV = 16.93/1.08⁵ = 11.52

5年显式期PV合计 = **63.48亿** [calc: sum of above]
终值 = 16.93 × 1.02 / (0.08−0.02) = 287.81亿
终值PV = 287.81 / 1.08⁵ = 195.90亿
企业总价值 = 63.48 + 195.90 = 259.38亿

| 情景 | 企业价值（亿） | 每股内在价值（元） | 现价 vs 内在价值 |
|---|---|---|---|
| 悲观 | 146.0 | 36.87 | 现价67.6%溢价 |
| **基准** | **259.4** | **65.49** | **现价5.6%折价** |
| 乐观 | 328.4 | 82.93 | 现价25.5%折价 |

现价61.80元落入悲观~基准之间。结论：**基准情景下存在约6%的微弱安全边际，但悲观情景无保护**。DCF不触发VETO（价格未超过乐观情景），但安全边际脆弱——FCF的微小恶化就会消灭它。

**魔鬼代言人问题：DCF敏感性**。FCF_TTM 14.60亿中包含了2025Q4单季OCF高达9.95亿 [source: quarterly.periods[1].ocf_yi]——这是季节性的还是可持续的？2024Q4 OCF为7.03亿 [source: quarterly.periods[5].ocf_yi]，2025Q4同比大幅改善。但如果2025年的OCF爆发包含了一次性因素（如应收账款回收加速），FCF_TTM就会高估可持续现金流。终端增长率每变动0.5%，基准内在价值变动约±12%。

### 9. 捡漏 vs 价值陷阱（综合判断）

**触发条件检查**：9项中哪些显示「低估」？仅盈利收益率一项勉强算低估信号（剩余各项显示高估或公允）。**不满足「≥2项显示低估」的捡漏触发条件**。但为完整起见，仍执行框架：

**四线验证**：

- **线1 格雷厄姆底线**：Graham Number 36.33 < 股价61.80 × 1.2 = 74.16，且 股价61.80 远大于 NCAV×2/3 → ❌ 不通过
- **线2 林奇性价比**：PEG = PE / 5年利润CAGR = 16.60 / 25.77 = 0.64 [calc: 16.6002/25.77; inputs: market.pe_ttm, annual.profit_cagr_5y_pct]。PEG < 1 → ✅ 通过。但要警惕：CAGR来自过去5年的高增长期（2020-2024），而2025年利润已下降3.50%，这个PEG是后视镜里的流星。
- **线3 特殊情况**：无隐蔽资产（商誉未披露非零 [source: data_quality.warnings]，现金50.61亿对应市值244.71亿，占比20.7% [calc: 50.61/244.71*100; inputs: balance.cash_yi, market.total_mv_yi]但不构成隐蔽资产逻辑）。非困境反转，非周期底部 → ❌ 不通过
- **线4 邓普顿极度悲观点**：PE 16.6倍、PB 3.85倍，市场远未到「第99个人放弃」的程度。日化行业竞争激烈但并非灾难性衰退。→ ❌ 不通过

**结果**：仅线2（PEG）通过 → 「待观察」等级。

### 加分项

- **廉价证券筛查**：股价61.80 ≫ 每股净流动资产（粗估≥8.64）→ 不成立
- **股利持续性**：数据未提供分红历史 → 无法评估
- **降维三变量检查**：当前分析聚焦企业价值判断（盈利质量好）和产业趋势（行业增速5.1%，公司年增速−1.68%，已经跑输行业）。系统性风险方面，M1-M2剪刀差−4.0% [source: macro.indicators.money_supply.latest_scissors_pct]，流动性偏紧但非危机水平。公司估值虽不便宜，但也未到泡沫区间。三变量中，最大的不确定性不在估值模型参数而在「产业趋势判断」——化妆品市场竞争烈度持续上升，珀莱雅主品牌2025年营收下滑10.39%是一个不可忽视的转折信号。
- **极端斯坦校准**：化妆品行业属于「平均斯坦」还是「极端斯坦」？品牌消费品通常在两者之间——常规年份平稳，但社交媒体时代的品牌崩塌可以是极端斯坦事件（一条负面热搜就可能造成不可逆的品牌伤害）。珀莱雅严重依赖线上渠道（线上占比95.58%），意味着品牌情绪在社交媒体上的波动会快速传导为销售波动。当前的安全边际（DCF基准仅6%）在极端斯坦视角下是不够的——如果主品牌继续以−10%的速度萎缩而新品牌无法完全弥补，基准假设就会崩塌。邓普顿会等待更大的折扣。

| 5 | “线上渠道为主、线下渠道并行...2025年度珀莱雅天猫旗舰店成交金额获天猫美妆排名第1”（年报:2025年年度报告/经营模式+渠道） | `annual.annual_data` 渠道拆分 | ❓ 排名不可验证 | 天猫排名数据来自第三方平台统计，无法通过财务数据直接验证。但线上总营收101.17亿占总营收95.58% [calc: 101.17/105.85*100]，线上分销同比下降8.84%——整体线上小计−1.14%与总量−1.68%一致，说明线上渠道本身不再是增长引擎。 |

**交叉验证发现**：管理层年报存在明显的「不对称乐观」——对少数高增长新品牌浓墨重彩（OR、原色波塔），对占营收72.6%的主品牌的10.39%下滑轻描淡写。毛利率改善被归因为「降本」，但同时销售费用率创历史新高（49.63%）。这不是造假，但选择性披露使得仅读年报文字会形成「一切向好」的错误印象——而数字说的是「主引擎在熄火，新引擎还太小」。

## 关键风险与不确定性

1. **主品牌萎缩的持续性**：珀莱雅品牌营收−10.39%是2025年最大的风险信号。如果这反映的是品牌生命周期见顶（而非一次性电商平台策略调整），那么未来FCF增长假设需要大幅向下修正。目前无法判断是拐点还是波动。

2. **FCF_ttm的可持续性**：基准DCF使用的14.60亿TTM FCF高度依赖2025年OCF的爆发式增长（同比+98.12% [source: annual.annual_data]，年报:2025年年度报告/主要会计数据）。如果2026年OCF回落至2024年水平（11亿左右），基准DCF每股价值将从65.49元降至约49元。

3. **无风险利率的模糊性**：盈利收益率vs无风险利率的判定依赖于一个数据不可得的变量（10年期国债收益率）。虽然任何合理估计（2.0%–3.0%）都不会改变PASS结论，但这是一个需要标注的缺口。

4. **数据缺失**：有息负债分项未披露（标注为未知，不得按0处理）；PE历史序列缺失；分红历史缺失；商誉未披露。这些缺口对估值结论的影响程度不一——有息负债缺失影响最小（现金远超任何可能的负债），PE历史缺失影响较大（无法做历史分位对标）。

## 数据使用说明

**使用的主要数据**：`annual.annual_data`（12年利润/营收序列）、`balance`（2023–2025年资产负债表）、`market`（行情数据）、`quarterly`（单季FCF和OCF）、`indicators`（6年ROE/毛利率/净利率序列）、`industry`（日化行业19家同行对比）、`macro`（Shibor/PMI/CPI/货币供应量）。

**数据缺失**：10年期国债收益率（用Shibor + 分析师估计代替）、PE历史序列（无法做分位）、有息负债分项（标注unknown，净现金结论降级但非否决）、分红历史、商誉数据。年报文本只提供了2021/2023/2024/2025四年关键章节，缺少2022年年报。
